## 🚀 Quick Start

### Prerequisites
- Node.js 18+ OR Bun
- npm / pnpm / bun

### Local Development

```bash
# Install dependencies
npm install
# or
bun install

# Start dev server
npm run dev
```

The app runs on http://localhost:5173 (Vite default).

### Production Build

```bash
npm run build
npm run preview
```

## 🏗️ Stack

- **Vite** + **React** + **TypeScript**
- **Tailwind CSS** for styling
- **shadcn/ui** components
- Bundled with **Bun** for fast iteration
